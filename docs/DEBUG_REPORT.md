## Проверка браузера

Локальный сайт использует настоящий API и CSV. Отдельный временный harness вне
репозитория имитировал только задержку, 500, 503 и повреждённый ответ.

- Пустая форма: ошибки обязательных полей и фокус на первом.
- Алматы / ведущий / корпоратив / 15.10 / 1 200 000: 3 карточки из 6.
- Изменение на 19.12 убирает старую выдачу; новый подбор — 1; применение 17.12 — 3.
- Астана / декоратор: category_absent; выбор категории сохранён после смены города.
- Астана / флорист / 15.10 / 100 000: no_eligible; применение 16.10 + 300 000 — 1.
- У карточки виден флаг synthetic и четыре раскрывающихся раздела.
- Мобильный viewport 390 × 844: нет горизонтальной прокрутки, карточка читается.
- Редактирование во время задержки 8 с: ответ проигнорирован, старые варианты не возвращаются.
- Повреждённый JSON-ответ и 500: понятная ошибка, код обращения, форма сохранена.
- Ответ дольше 10 с: timeout, загрузка завершена, повтор разрешён.
- Сбой справочника 503: поля заблокированы, кнопка «Повторить» восстанавливает форму.
- В обычных сценариях ошибок JavaScript в консоли не было; искусственные 500/503
  создавали ожидаемые сообщения HTTP, без падения интерфейса.
