У двух фотографов — живые эмоции и работа незаметно для гостей. Это ручная проверка небольшого набора. Она не доказывает полную невзаимозаменяемость всех похожих профилей. У площадок описания близки; отсутствие одинаковых строк ещё не означает смысловую уникальность.

Список слов-подсказок используется только для фрагментов объяснения. Отсечение общей рекламы и выбор из короткого списка улучшают эти примеры, но не являются полноценной проверкой смысла произвольного пожелания. Положительный brief также не считается автоматически доказанным целиком.

## Проверка транспорта и отказов

- Реальный Uvicorn на 127.0.0.1: health и четыре одновременных POST вернули HTTP 200; одинаковые id; замер 70,04–72,17 мс на запрос в local. Сервер после проверки остановлен.
- Полная имитация зависшего AI-вызова при обычном лимите 6 секунд: HTTP 200, ai_reason=timeout, проверенное локальное объяснение за 6,041 с. Это имитация, не сетевой запрос к провайдеру.
- Отдельные тесты проверяют четыре одновременных тайм-аута, отмену coroutine, 401/403, 429, 500, сетевой сбой, невалидный JSON, неверные/повторные id и неподтверждённые цитаты.
- 26 unittest-тестов прошли локально на предыдущем этапе после объединения с cf3d1af. Повторное локальное демо того этапа: 0,07–78,95 мс; статусы и порядок карточек сохранены. GitHub Actions отключён по решению команды; проверка выполняется локально. Итог следующей итерации — 40 тестов — приведён ниже.
- Живые OpenAI/NVIDIA в этой итерации не вызывались: доступ команды не подтверждён. Время и качество реального AI остаются непроверенными.

Для повторения используйте команды из README. `--provider openai` или `--provider nvidia` — отдельный явный живой прогон с настроенным ключом; ключи и купоны не входят в проект.

## Интеграция с фронтендом

На 23.09.2026 проходят 46 Python-тестов и 12 Node-тестов. Экспортируемый контракт совпадает с работающим API; TypeScript-объявления проверены компилятором в strict-режиме. Проверены CORS preflight, единые ошибки, типы полей формы, отмена/timeout и защита от устаревшего ответа.

Через реальный Uvicorn и готовый JavaScript-клиент проверены справочник, health, выдача одного ведущего 19.12, применение даты 17.12 с тремя подходящими и ошибка 422 для строкового бюджета. Разрешённый origin получал CORS-заголовок. Это local + tfidf и реальный HTTP; интеграция визуального интерфейса команды и живые внешние модели в этот прогон не входят.
