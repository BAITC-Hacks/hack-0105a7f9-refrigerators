## Сравнение с исходной версией fda7115

До правок сохранены восемь контрольных запросов и ответы. Повтор тех же параметров после исправлений сохранил состав и порядок всех карточек. Формула ранжирования не менялась; изменения относятся к выбору и проверке доказательств.

Ожидаемые свойства были определены по запросам и описаниям: опыт делового форума/стиль для ведущих, живые эмоции и незаметная работа для фотографов, отсутствие обещания выполнить отрицательное пожелание.

У выбранных ведущих остаются разные исходные детали: бизнес-форумы на 3000 человек, перечисленные форматы/конференции, импровизация и интеллигентный юмор. У двух фотографов — живые эмоции и работа незаметно для гостей. Это ручная проверка небольшого набора. Она не доказывает полную невзаимозаменяемость всех похожих профилей. У площадок описания близки; отсутствие одинаковых строк ещё не означает смысловую уникальность.

Список слов-подсказок используется только для фрагментов объяснения. Отсечение общей рекламы и выбор из короткого списка улучшают эти примеры, но не являются полноценной проверкой смысла произвольного пожелания. Положительный brief также не считается автоматически доказанным целиком.

## Проверка транспорта и отказов

- Реальный Uvicorn на 127.0.0.1: health и четыре одновременных POST вернули HTTP 200; одинаковые id; замер 70,04–72,17 мс на запрос в local. Сервер после проверки остановлен.
- Полная имитация зависшего AI-вызова при обычном лимите 6 секунд: HTTP 200, ai_reason=timeout, проверенное локальное объяснение за 6,041 с. Это имитация, не сетевой запрос к провайдеру.
- Отдельные тесты проверяют четыре одновременных тайм-аута, отмену coroutine, 401/403, 429, 500, сетевой сбой, невалидный JSON, неверные/повторные id и неподтверждённые цитаты.
- 26 unittest-тестов прошли локально после объединения с cf3d1af. Повторное локальное демо: 0,07–78,95 мс; статусы и порядок карточек сохранены. GitHub Actions отключён по решению команды; проверка выполняется локально. Повторный прогон текущего `main`: 26 тестов прошли.
- Живые OpenAI/NVIDIA в этой итерации не вызывались: доступ команды не подтверждён. Время и качество реального AI остаются непроверенными.

Для повторения используйте команды из README. `--provider openai` или `--provider nvidia` — отдельный явный живой прогон с настроенным ключом; ключи и купоны не входят в проект.
