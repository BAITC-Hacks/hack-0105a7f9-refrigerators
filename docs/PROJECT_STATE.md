# Состояние проекта

Обновлено 23.09.2026 после аудита по FIREBIRD_MASTER_PROMPT.

## Подтверждено

- Основная поставка — FastAPI и CLI с общей бизнес-логикой; веб-интерфейс не добавлялся.
- Исходный CSV не изменён: 66 профилей, 13 synthetic, SHA-256 `6a724b6b7dfb5973343e68ba18dadb60fc807d87e3d78f03ee86fb26cb089f7d`.
- Фильтры выполняются до ранжирования; цена «от», календарь 23.09–31.12.2026, null часов не ограничивает длительность.
- Ранжирование char-tfidf-3-5-v1 сохранено. Порядок всех восьми исходных контрольных запросов совпал с базой fda7115.
- Один валидатор для AI и локальных цитат; отрицательные пожелания получают явное уточнение.
- Добавлены ai_reason, counts и evidence_note с сохранением старых полей ответа.
- Неизвестный провайдер — ошибка конфигурации; boolean бюджета, NaN/Infinity, лишние поля и слишком длинные строки отклоняются.

## Проверки

- Исходно: 12 тестов прошли. После изменений: 26 тестов прошли командой `python -m unittest discover -s tests -v`.
- Реальный CLI: `python -m contractor_match.demo --json`; восемь сценариев, локальный режим, без внешних API.
- Реальный Uvicorn: health, четыре одновременных POST, одинаковые id, ошибочный boolean-бюджет даёт 422.
- Имитация зависшей модели: HTTP 200 с проверенным fallback через 6,041 с; общий лимит не перезапускается.
- GitHub Actions удалён по решению команды: репозиторий не запускает платные удалённые проверки. 26 тестов текущего `main` повторно прошли в локальной рабочей среде.
- Изменения cf3d1af объединены без переписывания истории: сохранены сообщение о занятых, выбор различных цитат и дополнительные проверки демо. После объединения прошли 26 тестов и все восемь сценариев.
- Локальное окружение: Windows, Python 3.14.7, FastAPI 0.141.1, Pydantic 2.13.5, HTTPX 0.28.1, Uvicorn 0.53.0. Есть предупреждение Starlette о будущем переходе TestClient с httpx; проверки проходят.

## Провайдеры и ограничения

- local работает; openai/nvidia проверены имитациями, живые вызовы в этой итерации не выполнялись.
- Доступность NVIDIA для команды не подтверждена; выводов о доступности целой страны не делаем.
- .env не читается автоматически. auto выбирает OpenAI при ключе, затем NVIDIA; после ошибки переключений нет.
- Сходство текстов и словарь подсказок не доказывают выполнение произвольного пожелания. Самореклама остаётся цитатой профиля, а не независимой оценкой.
- Данные кэшируются; для изменения CSV требуется перезапуск.

## Следующий приоритет

Подтвердить на размеченных запросах смысловую релевантность и различимость объяснений для похожих профилей; при настроенном разрешённом ключе отдельно запустить живое демо. Проверенные предложения изменить запрос — возможная следующая P1-задача. Новую инфраструктуру пока не добавлять.
