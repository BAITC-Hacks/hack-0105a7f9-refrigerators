## Что исправлено для публикации

- Адрес localhost в frontend заменён общим origin. Форма работает на публичном домене.
- Локальный и облачный запуск используют одно приложение. В HTTP открыт только frontend
  и JS-клиент; весь корень репозитория и папка integration не монтируются.
- Добавлен источник Supabase с проверкой каталога, безопасным 503 и восстановлением
  после неудачной загрузки. Ключ остаётся только в серверной конфигурации.
- SQL-права и RLS проверены на созданной базе; таблица доступна серверу только для чтения.
- Сборка Vercel проверена на реальном deployment; версии зависимостей зафиксированы.
- Подсказка doctor с same-origin портом 8000 исправлена: отдельное CORS-разрешение
  нужно только при разных origins. Сохранены командный дизайн и решение не включать Actions.

## Границы текущей версии

Избранное, общая команда подрядчиков под одним бюджетом, аккаунты, бронирование и
реальные ссылки «Поделиться» из мобильного концепта ещё не реализованы. NIM/Brev
подготовлен кодом, но GPU и живые модели не подключались. Открытый PR #2 не закрывался
и не сливался целиком: дальнейшую интеграцию дизайна следует выполнять поверх HTTP-клиента main.
