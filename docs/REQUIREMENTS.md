# Соответствие ТЗ Firebird #79-lite

Источник требований — приложенный DOCX «Хакатон-задача: умный подбор подрядчиков». Факты — исходный CSV, HTML не используется для извлечения полных описаний. Аудит начат с коммита `fda7115`: рабочее дерево было чистым, 12 исходных тестов прошли. Хеш CSV совпал с файлом участника.

## Что не проверено или оставлено на следующую итерацию

- Живые вызовы OpenAI, NVIDIA Build и NIM на Brev: доступ и учётные данные команды не подтверждены; тесты используют имитации.
- Полное смысловое выполнение произвольного brief и всех видов отрицаний: текстовые эвристики этого не гарантируют.
- Предложения изменить дату/бюджет/часы добавлены: одиночные и составные варианты повторяют общий фильтр; test_rescue проверяет минимальность, границы и повтор запроса.
- Нагрузки публичного сервиса: проверено четыре одновременных запроса, а не длительный нагрузочный тест.
- Бронирование и обновление календаря из реального бизнеса не входят в решение.

## Дополнения по запросу команды

Альтернативы, локальный разбор brief, сравнение карточек и опциональный NIM — продуктовые улучшения команды. Они не приписываются исходному ТЗ. Набор test_rescue добавляет 14 проверок к 26 прежним: итог 40. Основной TF-IDF сохранён; семантическое качество и повторяемость живого NIM требуют отдельного измерения. Шесть секунд теперь делятся между ранжированием и объяснениями, без цепочки повторных попыток.
