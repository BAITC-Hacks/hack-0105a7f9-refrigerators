# Event Match — веб-интерфейс

Люди для вашего события: подбор подрядчиков по категории, городу, дате, формату, бюджету, длительности и пожеланиям.

## Запуск

Из корня репозитория:

```sh
python3 -m http.server 4317 --bind 127.0.0.1 --directory prototypes/offline-web/dist
node prototypes/offline-web/tests/planner.test.mjs
```

Откройте http://127.0.0.1:4317. В отдельном архиве используйте `--directory dist` и `node tests/planner.test.mjs`. Установка пакетов и сборка не нужны.

## Интерфейс

Категория — первое поле формы. Разделы: «Рекомендации», «Остальные подрядчики» и «Другие условия».

В карточках указана только стартовая цена «от» и описание. Подробный прайс, расчёт верхней цены и резерв удалены. Кнопка «Подробнее» открывает единое резюме: форматы, языки, длительность, доступность, полное описание и пояснения к пожеланиям. Отдельных вкладок прайса и соответствия, ID и поля источника в резюме нет.

«Остальные подрядчики» показывает кликабельные профили выбранной категории и города, не вошедшие в первые три. Причины и подходящие кандидаты вне тройки доступны через фильтры.

## Другие условия

Предложения появляются, когда подходят меньше трёх подрядчиков. Все варианты проверяются повторно по каталогу и показывают точное число подходящих кандидатов.

- Даты не дальше семи дней в пределах календаря; при одинаковом расстоянии предпочтительнее более поздняя дата.
- Ближайшее повышение бюджета не более чем на 25%.
- Сокращение длительности не более чем на два часа.
- Похожие форматы: корпоратив/конференция, свадьба/той, юбилей/день рождения, той/юбилей. Это явное продуктовое правило близости, а не утверждение о взаимозаменяемости событий. Новый формат виден до применения.
- Если одного изменения недостаточно, проверяются сочетания тех же близких значений, начиная с наименьшего числа изменённых полей.

При отсутствии близких вариантов показывается понятное сообщение; увеличение бюджета в несколько раз не предлагается. Применение меняет форму и результаты. Кнопка возврата восстанавливает предыдущие условия. Город, категория, язык и пожелания не меняются автоматически.

## Синхронизация и ограничения

Локальные ранжирование и выбор цитат синхронизированы с Python-логикой коммита `3765876bf2e188746809687f42f974eba0bf39f7`. Теперь учитываются конкретность фрагмента, рекламные формулировки и отрицания в пожеланиях. Язык из отдельного поля имеет приоритет над текстом, как в актуальном Python-сервисе. Несколько языков в тексте без отдельного выбора не включают языковой фильтр.

Разбор пожеланий работает по ограниченным локальным правилам: стили, языки и отрицательные фрагменты. Это не универсальное понимание естественного языка. Отрицательные пожелания не считаются подтверждёнными по совпадению слов. Сохранено ранее запрошенное расширение «имя начинается на …» как явный фильтр; в Python API этого расширения нет.

Подбор и резюме используют 66 исходных анонимизированных профилей. Календарь охватывает 23.09–31.12.2026. Реальной верхней цены, подробных прайсов, связи с подрядчиками и бронирования нет. Признаки синтетических и восстановленных данных сохраняются в данных и карточках.

Веб-версия работает локально в браузере, не вызывает Python HTTP API или внешних AI-провайдеров. Новые серверные возможности Brev/NIM не выдаются за включённые в веб-версии. Python-файлы сохраняются без изменений.

## Проверки

`node prototypes/offline-web/tests/planner.test.mjs` проверяет 144 сценария и повторно применяет 94 предложения с проверкой количества кандидатов и ограничений близости. Проверены похожие форматы, отсутствие далёких предложений, язык, отрицания, имя и невалидные входные данные.

Дополнительно выполнены 107 сравнений с актуальной локальной Python-логикой: ID, порядок и цитаты совпали. В браузере проверены единое резюме, отсутствие резерва/прайса, похожий формат, применение и отмена изменений, кликабельные остальные подрядчики и ширина 390 px.

## Демонстрация

1. Начальные условия: ведущий в Алматы, корпоратив, 15 октября, бюджет 1 200 000 ₸. Подходят шесть; показаны первые три.
2. На 19 декабря подходит один. В «Других условиях» предложено 17 декабря — подходят трое.
3. На 15 октября с бюджетом 600 000 ₸ нет совпадений. Можно выбрать 650 000 ₸ либо 16 октября.
4. Для ведущего на день рождения 15 октября доступны предложения похожего формата — юбилея. Это изменение явно указано и применяется только кнопкой.
5. Бюджет 100 000 ₸ не вызывает предложения поднять его до 650 000 ₸: это вне установленного диапазона близости.
