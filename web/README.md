# Event Match — интерактивная веб-версия

Веб-интерфейс для каталога HackAlem AI. Содержит 66 исходных анонимизированных профилей и сохраняет признаки синтетических профилей и восстановленных данных.

## Запуск

Из корня репозитория:

```sh
python3 -m http.server 4317 --bind 127.0.0.1 --directory web/dist
```

Откройте http://127.0.0.1:4317. Если скачан отдельный архив, перейдите в его папку и используйте `--directory dist`. Сборка и установка пакетов не нужны.

## Что работает

- Бриф: город, категория, дата, формат, бюджет, длительность, язык и пожелания.
- «Выбор»: до трёх профилей, факты, цитаты и неподтверждённые пожелания.
- «За кадром»: кликабельный список всех остальных профилей выбранных города и категории. Есть фильтры причин и отдельная группа подходящих кандидатов вне тройки.
- «План Б»: проверенные альтернативы даты, бюджета и длительности; при отсутствии категории — другие города. Когда одного изменения недостаточно, рассматриваются сочетания даты, бюджета и длительности. Применение обновляет форму и результаты; отмена возвращает предыдущие условия.
- Досье: отдельные вкладки расчёта цены, соответствия и полного описания.
- Клавиатурная навигация вкладок, модальное окно с Escape, мобильная вёрстка, состояния загрузки и ошибок.
- WebMCP: `find_event_contractors` использует те же действия, что и видимая форма, и возвращает подходящих, исключённых и альтернативы.

## Честные границы

**Цены.** В исходном каталоге есть только `price_from_kzt`. Реальных верхних тарифов и подробной разбивки услуг нет. Интерфейс показывает расчёт для планирования: стартовая цена + выбранный резерв (по умолчанию 20%, варианты 0/10/20/30/50%). Это явно подписано как расчёт, а не тариф или предложение подрядчика. Неизвестные цены допуслуг обозначены как отсутствующие. Проверка бюджета использует стартовую цену; превышение бюджета с резервом показывается отдельно.

**Пожелания.** Это локальный разбор ограниченного набора конструкций, не универсальное понимание естественного языка. Распознаются несколько стилей, деловая направленность, язык, «без конкурсов» и «имя начинается на …». Язык и начало имени применяются как условия. Явное противоречие пожеланию «без конкурсов» исключает профиль. Отсутствие подтверждения не выдаётся за выполнение пожелания. Близкие формулировки стиля влияют на порядок, но не являются гарантией. Остальной текст участвует в исходном сравнении описаний.

**Даты.** Доступность отражает только календарь датасета: 23.09–31.12.2026. Связи с подрядчиками, бронирования и живого календаря нет.

**AI.** Эта версия работает в браузере без AI-ключей и без обращения к Python API. Серверные функции провайдеров не заменяются этим интерфейсом.

## Устройство

- `dist/matcher.mjs`: порт базовой локальной логики Python по состоянию `cf3d1afc894b12b161829998dec64ea0b7b105bf`, включая общий выбор цитат, нормализацию и проверку каталога. Добавлен полный список подходящих для интерфейса.
- `dist/planner.mjs`: разбор пожеланий, оценка свидетельств, исключённые профили и проверка альтернатив. Распознанное соответствие может менять порядок базового подбора.
- `dist/app.js`: общий интерфейс, модальные подробности, расчёт цены и WebMCP.
- `dist/catalogue.json`: снимок исходного `data/contractors.csv`. После изменения CSV снимок нужно обновить отдельно.

Python-сервис и его существующие файлы не изменяются.

## Проверка

Из корня репозитория, при установленном Node.js:

```sh
node web/tests/planner.test.mjs
```

Для отдельного архива: `node tests/planner.test.mjs`.

Проверены 32 сочетания города, категории, даты и бюджета; 28 альтернатив повторно применены с проверкой точного количества кандидатов. Также проверены полнота исключённых, начало имени, конфликт языка, осторожная оценка «без конкурсов», невалидные даты и арифметика резерва. Базовый `matcher.mjs` отдельно прошёл 107 сравнений с локальной Python-логикой указанного коммита до добавления надстройки планировщика.

В браузере проверены переходы по вкладкам, открытие исключённого профиля, изменение резерва, применение/отмена плана Б, пустая выдача, WebMCP и ширины 390/1440 px.

## Сценарий защиты

1. Откройте подбор по умолчанию: Алматы, ведущий, корпоратив, 15 октября, 1 200 000 ₸. Подходят шесть, показаны три.
2. Откройте «За кадром»: ещё три проходят условия, остальные исключены с объяснениями.
3. Измените дату на 19 декабря: подходит один ведущий.
4. Откройте «План Б»: 17 декабря подходят трое. Примените и верните исходные условия.
5. Вернитесь к 15 октября, уменьшите бюджет до 100 000 ₸: совпадений нет. План Б предлагает минимальный подходящий порог 650 000 ₸.
6. В пожеланиях укажите «Имя начинается на А»: отображается Аня Форджер.
7. Откройте подробности: покажите расчётный диапазон, измените резерв и объясните отличие подтверждённых данных от неизвестных.
