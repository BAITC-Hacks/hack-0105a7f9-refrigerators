# Веб-страница «рядом.»

## Быстрый локальный запуск

На Windows дважды нажмите `start-web.cmd` в корне проекта. Скрипт установит Python-зависимости, запустит сайт и API вместе и откроет `http://127.0.0.1:8000/web/` в браузере. Терминал должен оставаться открытым, пока вы пользуетесь страницей.

Если зависимости уже установлены, запустите из корня проекта:

```powershell
python run_web.py
```

Для запуска без автоматического открытия браузера используйте `python run_web.py --no-browser`. Если порт 8000 занят, передайте `--port 8001` и откройте адрес, напечатанный в терминале. При таком запуске страница и API доступны на одном адресе, поэтому отдельный HTTP-сервер и настройка CORS не нужны. По умолчанию используются локальное объяснение и TF-IDF ранжирование; платный AI API для этого не требуется.

Форма получает справочник из `/catalogue/options`, рекомендации и проверенные запасные варианты из `/recommendations`. Данные берутся из `data/contractors.csv`. Изменение даты или бюджета для запасного варианта применяется только после нажатия пользователем.

`index.html` через `file://` не обращается к API: открывайте HTTP-адрес выше. Для диагностики API используйте `/health` или `python -m contractor_match doctor --frontend-origin http://127.0.0.1:8000`.
